## Overview

The SignIn component provides a complete, production-ready authentication form with support for multiple layouts, themes, social login options, and extensive customization capabilities. It's designed to be flexible, accessible, and easy to integrate into any React application.

### Key Features

- **Multiple Layouts**: Centered and split layout options
- **Visual Themes**: Default, modern, glass, and dark variants
- **Social Login**: Google, GitHub, and Microsoft integration
- **Customizable Content**: Complete control over left panel content in split layout
- **Accessibility**: Built with ARIA labels and keyboard navigation
- **Responsive**: Works on all screen sizes
- **Animations**: Smooth transitions with Framer Motion
- **Validation**: Built-in form validation

## Quick Start

Import the component and start using it:

```tsx

import { SignIn } from '@site/src/components/UI/signin';

function LoginPage() {
  const handleSubmit = async (data) => {
    console.log('User data:', data);
    // Your authentication logic here
  };

  return (
    <SignIn 
      type="centered"
      variant="dark"
      companyName="MyApp"
      onSubmit={handleSubmit}
      showSocialLogin={true}
    />
  );
}
```

## Usage Examples

### Form Handling with Validation
<div className="w-full h-[500px] overflow-y-scroll">
    ```tsx
import React, { useState } from 'react';
import { SignIn } from '@site/src/components/UI/signin';

function ControlledSignIn() {
  const [loading, setLoading] = useState(false);
  const [error, setError] = useState('');
  
  const handleSubmit = async (data) => {
    setLoading(true);
    setError('');
    
    try {
      // Your API call here
      const response = await fetch('/api/login', {
        method: 'POST',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify(data)
      });
      
      if (!response.ok) {
        throw new Error('Login failed');
      }
      
      // Handle successful login
      console.log('Login successful:', data);
    } catch (error) {
      setError('Invalid credentials. Please try again.');
    } finally {
      setLoading(false);
    }
  };

  return (
    <SignIn 
      onSubmit={handleSubmit}
      loading={loading}
      error={error}
      type="centered"
      variant="default"
      companyName="MyApp"
    />
  );
}
```

## Props
### Basic Props
| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `type` | `'centered' \| 'split'` | `'centered'` | Layout type - centered or split layout |
| `variant` | `'default' \| 'modern' \| 'glass' \| 'dark'` | `'default'` | Visual theme variant for the form |
| `companyName` | `string` | `'YourBrand'` | Company/brand name displayed in the form |
| `logo` | `React.ReactNode` | `<Shield /> icon` | Custom logo component (defaults to Shield icon) |
| `loading` | `boolean` | `false` | Loading state for form submission |
| `error` | `string` | `''` | Error message to display above the form |
| `showSocialLogin` | `boolean` | `true` | Show/hide social login buttons |
| `showForgotPassword` | `boolean` | `true` | Show/hide forgot password link |
| `showSignUpLink` | `boolean` | `true` | Show/hide sign up link |
| `onSubmit` | `(data: SignInFormData) => void` | `-` | Callback function when form is submitted (after validation) |
| `onSignUp` | `() => void` | `-` | Callback function when user clicks sign-up link |
| `onGoogleSignIn` | `() => void` | `-` | Callback function for Google sign-in |
| `onGitHubSignIn` | `() => void` | `-` | Callback function for GitHub sign-in |
| `onMicrosoftSignIn` | `() => void` | `-` | Callback function for Microsoft sign-in |
| `className` | `string` | `''` | Additional CSS classes for the component container |

### Split Background Props (Split Layout Only)
| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `splitBackground.gradient` | `string` | ``'bg-gradient-to-br from-blue-600 via-blue-700 to-blue-800'` (default variant)<br>`'bg-gradient-to-br from-gray-900 via-gray-800 to-gray-900'` (dark variant)` | Background gradient classes for left panel |
| `splitBackground.textColor` | `string` | `'text-white'` | Text color for left panel content |
| `splitBackground.companyNameColor` | `string` | `'text-white'` | Override company name color |
| `splitBackground.descriptionColor` | `string` | `'text-white/90'` | Override description color |
| `splitBackground.leftPanelClassName` | `string` | `''` | Custom CSS classes for left panel |
| `splitBackground.backgroundImage` | `string` | `-` | Background image URL (overrides gradient) |
| `splitBackground.overlayColor` | `string` | `-` | Overlay color for background image |
| `splitBackground.rightPanelClassName` | `string` | `''` | Custom CSS classes for right panel |

### Button Style Props
| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `buttonStyle.gradient` | `string` | `'bg-gradient-to-r from-blue-600 to-blue-700'` | Background gradient classes for sign in button |
| `buttonStyle.hoverGradient` | `string` | `'hover:from-blue-700 hover:to-blue-800'` | Hover gradient classes for sign in button |
| `buttonStyle.textColor` | `string` | `'text-white'` | Text color for sign in button |
| `buttonStyle.shadow` | `string` | `'shadow-lg'` | Button shadow classes |
| `buttonStyle.hoverShadow` | `string` | `'hover:shadow-xl'` | Hover shadow classes |
| `buttonStyle.className` | `string` | `''` | Custom CSS classes for the button |

### Left Panel Content Props (Split Layout Only)
| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `leftPanelContent.title` | `string \| React.ReactNode` | `"Welcome Back to {companyName}" (styled)` | Custom title text or component |
| `leftPanelContent.description` | `string \| React.ReactNode` | "Sign in to access your personalized dashboard..." | Custom description text or component |
| `leftPanelContent.subtitle` | `string \| React.ReactNode` | `-` | Custom subtitle text or component |
| `leftPanelContent.features` | `Array<Feature>` | 4 default features (security, performance, collaboration, availability) | Features/benefits list with icons and colors |
| `leftPanelContent.testimonials` | `Array<Testimonial>` | `-` | Customer testimonials/quotes |
| `leftPanelContent.statistics` | `Array<Statistic>` | `-` | Statistics to display with values and labels |
| `leftPanelContent.customContent` | `React.ReactNode` | `-` | Complete custom content (overrides all other content) |
| `leftPanelContent.footerText` | `string \| React.ReactNode` | `"© 2024 {companyName} • All rights reserved"` | Custom footer text or component |
| `leftPanelContent.hideBranding` | `boolean` | `false` | Hide default logo and company name |
| `leftPanelContent.contentClassName` | `string` | `''` | Additional CSS classes for content container |
| `leftPanelContent.layout` | `Object` | `{ align: 'center', maxWidth: 'max-w-2xl', animate: true }` | Layout options (align, maxWidth, animate) |
| `leftPanelContent.animationConfig` | `Object` | `{ titleDelay: 0.2, descriptionDelay: 0.3, featuresDelay: 0.4, staggerChildren: 0.1 }` | Animation timing configuration |
